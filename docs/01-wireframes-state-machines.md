# WYRM CHASE - Wireframes & State Machines

## Game Overview

**Concept**: Single-player survival chase game inspired by Nidhogg mechanics. Player flees a pursuing wyrm-dragon through 5 screens per level, battling enemies with rotating weapons. Minimalist black-and-white sketch aesthetic.
